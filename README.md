# Personal Portfolio

Portfolio personal estático hecho con HTML y CSS, sin build ni dependencias. Proyecto de aprendizaje de front end: se mejora paso a paso siguiendo [PLAN.md](PLAN.md).

## Estructura

```
personal-portfolio/
├── index.html      # Página única
├── css/
│   └── styles.css  # Estilos
├── pics/           # Imágenes e íconos
├── PLAN.md         # Plan de mejora por pasos
└── README.md
```

> Rutas y nombres de archivo en minúsculas y sin espacios (GitHub Pages distingue mayúsculas).

## Cómo correrlo

Elige una opción:

1. Abrir `index.html` directamente en el navegador.
2. Live Server (extensión de VS Code): clic derecho en `index.html` > "Open with Live Server".
3. Servidor local con Python, desde la raíz del proyecto:
   ```
   python -m http.server
   ```
   y abrir http://localhost:8000.
